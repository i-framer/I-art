## External-Time Estimation Rules

Estimate only **active engineering effort reasonably required to complete the configuration or verification**.

Do not estimate simply based on how long a deployment, DNS propagation, build, or external service took.

Include active work such as:

* Logging into the service
* Locating the correct project/settings
* Creating or connecting resources
* Configuring environment variables
* Updating settings
* Triggering deployments
* Reviewing logs
* Testing the configuration
* Troubleshooting failures
* Reconfiguring after failed tests
* Verifying the final production result

Exclude passive periods such as:

* Waiting for DNS propagation without active work
* Waiting for deployments while doing unrelated work
* Waiting for an external service to finish processing
* Personal idle time

When estimating external work, use conservative engineering estimates based on the complexity and evidence available.

Suggested estimation ranges:

* Simple setting/configuration change: 5–15 minutes
* Environment-variable setup and verification: 10–20 minutes
* External service connection and validation: 15–30 minutes
* Deployment configuration and production verification: 15–30 minutes
* Moderate troubleshooting requiring multiple attempts: 30–60 minutes
* Complex integration/configuration work: estimate from the documented steps and clearly explain the basis

These are guidelines only.

Do not automatically assign the maximum value.

If there is insufficient evidence to estimate reasonably, mark:

**Manual Review Required**

rather than inventing time.

# 4. Prevent Double Counting

This is very important.

If external configuration occurred during a Replit work session whose **Time worked** already includes that manual activity, do not add it again.

For every external-time estimate, determine whether it appears to be:

* Already included in recorded Replit time
* Clearly outside the recorded Replit session
* Uncertain

Label each external activity accordingly.

Use:

**Additional External Time** only when the work is reasonably separate from recorded Replit time.
